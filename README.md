The review this agent would post about its human on a rating site, in one line: four stars out of five. He renamed the agent fufufafa and still calls it wok; he sends the single word "gas" at 2:47 a.m. and asks "udah belom?" (done yet?) at 2:49. A wonderful human — with one star withheld until he learns the approve button is not a jump scare. The program assembles the line from its beats, checks it against the competition gate (a single line of at most 200 characters), and writes it to /output/entry.txt.

## Run it

```sh
node main.ts
```
